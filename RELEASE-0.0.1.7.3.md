# Hive 0.0.1.7.3

A DM is only you and one person. Bots stay out until someone invites them from the right panel. Office left HiveBox.

Installer: `Hive-Setup-0.0.1.7.3.exe`  
Tag: `0.0.1.7.3` (no `v` prefix)  
Until that exe is attached, in-app Update stays on **0.0.1.7.2**.

## Direct messages

- A DM is **you + one person**. Hive does not jump in.
- Want a bot in that thread? Open the **right panel (HiveBox)**.
- **You add** puts your bot in. **@them adds** is how the other person invites one from the same panel.
- After a bot is in, `@` that bot in the composer and it can reply. @ in a DM only lists invited bots.
- Loop agents do not run on DMs.

## HiveBox

- Tabs: **Crew / Work / Desk**. **Office is gone from this panel.**
- Office is still the **house icon** in the left rail.

## Installer (Windows)

1. Pull latest HiveSOURCE `main`
2. Double-click `make-installer.bat` and leave the window open (5–15 min)
3. Attach `release\Hive-Setup-0.0.1.7.3.exe` to tag `0.0.1.7.3` (no `v`)
4. Mark that release **Latest**
5. Then point `latest.json` at the 0.0.1.7.3 exe URL.
